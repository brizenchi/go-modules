# 管理员环境变量密码登录

用户要求为独立的 `/admin` 后台提供邮箱和密码登录，并从后端环境变量配置密码。

- `APP_AUTH_ADMIN_EMAIL` 与 `APP_AUTH_ADMIN_PASSWORD` 共同启用一个管理员密码账号。
- 配置启动时校验，密码不入库、不输出、不下发；密码登录走独立接口并限制尝试次数。
- 成功登录复用真实用户、签名令牌和现有管理员权限校验，刷新后保留管理员身份。
- 后台显示独立密码表单，用户工作台继续使用已有登录方式。
- 本地临时 SQLite 预览支持环境变量密码，运行不连接已有数据库，不执行部署迁移。

验收覆盖环境变量覆盖配置、错误/禁用/限流、登录及刷新后的管理 API 权限、
普通用户拒绝访问、异步登录会话竞争，以及前端类型检查、构建和浏览器交互。

## 完成与验收

- 前端 89 项测试通过，lint、类型检查和生产构建通过。
- 后端 platform、bootstrap、http/middleware 和 cmd/preview 的竞态检测测试通过。
- 浏览器确认错误密码提示，正确密码登录并保留 `/admin/settings`，实际管理页面可访问。
- 测试使用临时 SQLite 与本地预览；没有执行部署数据库迁移或修改已有数据库。

  仅用于本机预览，没有写入跟踪文件。
