# Template 产品介绍与使用指南

目标：首次访问者能够明确理解模板定位、已有功能、体验方式，以及如何配置自己的 SaaS。

- 总览首先说明免费 Next.js + Go 模板、交付源码、适合的产品和需要自行开发的核心业务。
- 区分公开官网、用户工作台和管理员后台，明确各自的数据范围与使用入口。
- 介绍登录、Stripe 订阅、Resend、邀请、运营配置，以及笔记、积分和私有图片示例。
- 提供注册、测试购买、邀请的可操作路径；测试支付以 Stripe 测试模式为前提。
- 邀请说明包含新账号归因、付费订阅或终身套餐激活、试用转付费与积分包的边界。
- 总览以六个步骤解释配置上线，具体变量集中在可搜索的使用指南，包含管理员邮箱密码。
- 中英文同步，保留用户工作台的权限边界，验证构建、章节链接和窄屏阅读。

事实依据：当前代码与配置示例；测试卡说明核对 https://docs.stripe.com/testing。
源码获取入口使用已验证可公开访问的 https://github.com/brizenchi/go-modules。

## 验证结果

- 89 项现有前端测试通过，lint、类型检查和最终生产构建通过。
- 首页及指南的章节链接检查无失效锚点。
- 浏览器检查了中英文首页、375px 手机页面、管理员环境变量搜索，以及搜索后跳转配置步骤。
- 修复手机文档中长变量名称撑宽卡片的问题；搜索后跨章节跳转会恢复完整指南。
- 本地预览运行于 http://localhost:3100，连接已有的隔离预览 API；没有发布网站或执行数据库变更。
